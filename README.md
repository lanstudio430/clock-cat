# 工時貓 Clock Cat

以 Google Apps Script 網頁應用程式搭配 Google Sheets 儲存資料的月行事曆，介面使用 Tailwind CSS 與 Font Awesome。

- 可切換年份、月份，一週從星期一開始
- 點擊日期格子可新增、編輯、刪除原定與實際上下班時間，以及假別（例假、休假、國定假日）
- 日曆以紅字顯示上下班時間：有填實際時間就顯示實際，否則顯示原定
- 每週右側顯示該週上班時數，最下方顯示週合計加總，只計算當月
- 可填寫每個月的應上班時數，填寫後顯示加班時數（週合計加總減應上班時數）

## 檔案

| 檔案 | 用途 |
| --- | --- |
| `Code.gs` | 後端：讀寫試算表、驗證資料 |
| `Index.html` | 前端：行事曆畫面 |

## 安裝

1. 到 [Google Sheets](https://sheets.new) 建立一份新的試算表。
2. 點選「擴充功能 → Apps Script」。
3. 把預設的 `Code.gs` 內容換成本專案的 `Code.gs`。
4. 點選檔案旁的「+ → HTML」，新增名為 `Index` 的檔案（大小寫需相同），貼上本專案的 `Index.html`。
5. 點選「部署 → 新增部署作業」，類型選「網頁應用程式」：
   - 執行身分：我
   - 誰可以存取：只有我自己
6. 按「部署」並完成授權，開啟產生的網址即可使用。

第一次開啟時會自動建立「班表」與「月設定」工作表。

修改程式後，需到「部署 → 管理部署作業 → 編輯 → 版本：新版本」重新部署，網址才會套用新程式。

畫面需要連上網路才能載入 Tailwind CSS、Font Awesome 與字型。

## 時間格式

時間以小數小時表示：`09:30` 是 `9.5`，`21:30` 是 `21.5`；整點在日曆上補零，例如 `09`。下拉選單可選 06 到 21 點，分鐘可選 `0`、`.25`、`.5`、`.75`。

上下班時間需成對選擇，將「時」選回 `--` 即可清除。一天可以只填原定、只填實際、只填假別，或同時填寫。

## 計算規則

- 週合計以日曆上顯示的時間計算：有填**實際**時間就用實際，沒填就用**原定**。
- 週合計為下班減上班，**不扣除休息時間**：`09` 到 `21.5` 算 12.5 小時。
- 週合計只計算當月日期：跨月的週，其他月份的日期在畫面上留白，時數也不計入。
- 週合計加總是當月所有週合計相加，也就是月上班總時數。
- 加班時數為週合計加總減應上班時數，可能是負數；未填應上班時數時不顯示。
- 下班時間必須晚於上班時間，不支援跨夜班。
- 每天只能有一段原定與一段實際上下班時間。

## 資料格式

「班表」工作表的每一列代表一天，所有欄位都是純文字：

| 日期 | 原定上班 | 原定下班 | 實際上班 | 實際下班 | 假別 |
| --- | --- | --- | --- | --- | --- |
| 2026-11-02 | 9 | 21.5 | 9.25 | 21.5 | |
| 2026-11-08 | | | | | 例假 |

「月設定」工作表的每一列代表一個月：

| 月份 | 應上班時數 |
| --- | --- |
| 2026-11 | 176 |

直接編輯工作表時請維持相同格式，日期必須是 `yyyy-MM-dd`、月份必須是 `yyyy-MM`，否則行事曆讀不到該列。

## 從舊版升級

舊版「班表」只有「日期、上班、下班、假別」四欄。新版第一次開啟時會自動轉換：舊時間轉成小數並放入實際上下班欄位，原定時間留空。

舊資料如果超出 06 到 21 點的範圍或不是整刻鐘，編輯時需要重新選擇；舊的跨夜班不會計入週合計，也需要重新填寫。
