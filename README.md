# 工時貓 Clock Cat

月行事曆工時記錄：原定與實際上下班、假別、週合計與加班時數。可安裝到手機主畫面，像 App 一樣使用，離線也能看與記。

```
手機 / 電腦 ── GitHub Pages（網頁前端，PWA）── fetch ──► Apps Script（API）──► Google Sheets
                     └ 本機快取與待同步佇列
```

- 可切換年份、月份，一週從星期一開始
- 點擊日期格子可新增、編輯、刪除原定與實際上下班時間，以及假別（例假、休假、國定假日）
- 日曆以紅字顯示上下班時間：有填實際時間就顯示實際，否則顯示原定
- 每週右側顯示該週上班時數，最下方顯示週合計加總，只計算當月
- 可填寫每個月的應上班時數，填寫後顯示加班時數（週合計加總減應上班時數）
- 儲存時先更新畫面，再於背景同步到試算表；離線時變更會留在手機上，恢復連線後自動送出

## 專案結構

| 路徑 | 用途 |
| --- | --- |
| `apps-script/Code.gs` | 後端：驗證密鑰、讀寫試算表，以 JSON 回應 |
| `docs/` | 前端網站，GitHub Pages 直接發布這個資料夾 |
| `docs/index.html`、`docs/app.js` | 畫面與邏輯 |
| `docs/styles.css` | 由 Tailwind 編譯出來的樣式（要一起提交） |
| `docs/sw.js`、`docs/manifest.webmanifest`、`docs/icons/` | PWA：離線外殼、安裝資訊、圖示 |
| `docs/vendor/fontawesome/` | Font Awesome 圖示字型（自行託管） |
| `src/input.css`、`tailwind.config.js` | Tailwind 設定與入口 |

## 安裝

### 1. 後端：Apps Script

1. 到 [Google Sheets](https://sheets.new) 用**個人 Gmail**建立一份新的試算表。
2. 點選「擴充功能 → Apps Script」，把預設的 `Code.gs` 內容換成 `apps-script/Code.gs`。
3. 在編輯器上方的函式選單選 `setupApiKey`，按「執行」並完成授權。
4. 開啟「執行記錄」，複製 `API_KEY:` 後面那串密鑰，先暫存起來。
5. 點選「部署 → 新增部署作業」，類型選「網頁應用程式」：
   - 執行身分：我
   - 誰可以存取：**任何人**
6. 按「部署」，複製「網頁應用程式網址」（結尾是 `/exec`）。

第一次讀寫時會自動建立「班表」與「月設定」工作表。

「任何人」是必要的：網頁在另一個網域，瀏覽器沒辦法帶著 Google 登入狀態呼叫。安全性靠密鑰：每個請求都要帶正確的密鑰，沒帶或不符一律拒絕，也不會回傳任何資料。

修改 `Code.gs` 後，需到「部署 → 管理部署作業 → 編輯 → 版本：新版本」重新部署，網址才會套用新程式。

換密鑰：到「專案設定 → 指令碼屬性」刪掉 `API_KEY`，再執行一次 `setupApiKey`，然後在每台裝置的設定裡貼上新密鑰。

### 2. 前端：GitHub Pages

1. 把專案推到 GitHub（公開 repo）。
2. 到 repo 的「Settings → Pages」，Source 選「Deploy from a branch」，Branch 選 `main`、資料夾選 `/docs`。
3. 等一兩分鐘，網址是 `https://<帳號>.github.io/clock-cat/`。

程式碼是公開的，但網址與密鑰都不在程式碼裡，資料也不在 repo 裡。

### 3. 第一次使用

1. 開啟網站，會跳出「連線設定」，貼上 Apps Script 的網址與密鑰後儲存。
2. 設定只存在這台裝置的瀏覽器裡，每台裝置各設定一次。

#### 安裝到 iPhone

1. 用 Safari 開啟網站，點「分享 → 加入主畫面」。
2. 從主畫面開啟「工時貓」，會是全螢幕、沒有網址列。
3. iPhone 的主畫面 App 與 Safari 的儲存空間是分開的，所以要在主畫面 App 裡再貼一次網址與密鑰（點右上角的齒輪）。

Android 的 Chrome 與電腦的 Chrome、Edge 也能安裝：網址列旁會出現安裝按鈕。

## 離線與同步

- 每個月份的資料會快取在裝置上，開啟時先顯示快取，再於背景更新；一次會取回前後各一個月，切換月份不用等。
- 儲存、刪除、修改應上班時數時，畫面立刻更新，變更先排進佇列再依序送出。
- 沒有網路時，變更留在佇列裡，畫面上方會顯示「N 筆變更尚未同步」，恢復連線或點「重試」後送出。
- 伺服器拒絕某筆變更時（例如資料不合規則），該筆會被丟棄並顯示原因，畫面回到試算表裡的內容。
- 試算表永遠是準的：同步完成後，畫面以試算表內容為準。
- 換成另一份試算表（更改網址）時，舊的快取與尚未送出的變更會清掉。

## 開發

```
npm install
npm run build
```

- 改了 `docs/index.html` 或 `docs/app.js` 裡的樣式類別後，執行 `npm run build` 重新產生 `docs/styles.css`，並把它一起提交。
- 本機預覽需要用網頁伺服器開啟 `docs/`（例如 `npx serve docs`），直接開檔案時 Service Worker 不會啟用。
- `docs/sw.js` 對同源檔案採「先用快取、背景更新」，改了程式碼不用改版號；只有新增或移除外殼檔案時，才需要更新 `SHELL` 清單並調整 `CACHE` 版號。

## 時間格式

時間以小數小時表示：`09:30` 是 `9.5`，`21:30` 是 `21.5`；整點在日曆上補零，例如 `09`。下拉選單可選 06 到 21 點，分鐘可選 `0`、`.25`、`.5`、`.75`。

上下班時間需成對選擇，將「時」選回 `--` 即可清除。一天可以只填原定、只填實際、只填假別，或同時填寫。

## 計算規則

- 週合計以日曆上顯示的時間計算：有填**實際**時間就用實際，沒填就用**原定**。
- 週合計為下班減上班，**不扣除休息時間**：`09` 到 `21.5` 算 12.5 小時。
- 週合計只計算當月日期：跨月的週，其他月份的日期在畫面上留白，時數也不計入。
- 週合計加總是當月所有週合計相加，也就是月上班總時數。
- 加班時數為週合計加總減應上班時數，可能是負數；未填應上班時數時不顯示。
- 下班時間必須晚於上班時間，不支援跨夜班。
- 每天只能有一段原定與一段實際上下班時間。

## 資料格式

「班表」工作表的每一列代表一天，所有欄位都是純文字：

| 日期 | 原定上班 | 原定下班 | 實際上班 | 實際下班 | 假別 |
| --- | --- | --- | --- | --- | --- |
| 2026-11-02 | 9 | 21.5 | 9.25 | 21.5 | |
| 2026-11-08 | | | | | 例假 |

「月設定」工作表的每一列代表一個月：

| 月份 | 應上班時數 |
| --- | --- |
| 2026-11 | 176 |

直接編輯工作表時請維持相同格式，日期必須是 `yyyy-MM-dd`、月份必須是 `yyyy-MM`，否則行事曆讀不到該列。

## 從 v1.0.0 升級

v1.0.0 是直接由 Apps Script 提供網頁的版本，v1.1.0 起改成 GitHub Pages 加 Apps Script API，功能與畫面不變。升級時：

1. 沿用原本的試算表，把 `Code.gs` 換成新版，並刪掉專案裡的 `Index` 檔案。
2. 照上面的步驟執行 `setupApiKey`，並把部署的存取權限改成「任何人」，重新部署新版本。
3. 試算表裡的資料不需要轉換。

更早的版本只有「日期、上班、下班、假別」四欄。第一次讀取時會自動轉換：舊時間轉成小數並放入實際上下班欄位，原定時間留空。舊資料如果超出 06 到 21 點的範圍或不是整刻鐘，編輯時需要重新選擇；舊的跨夜班不會計入週合計，也需要重新填寫。
