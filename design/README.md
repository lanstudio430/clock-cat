## 原則

- 跟圖示同一套畫風：深褐粗輪廓、硬陰影、圓角，像貼在手帳上的貼紙。
- 只做淺色模式。
- 手機優先；所有可點的東西至少 44×44px。
- 一般文字對比度至少 4.5:1；只靠顏色表達的資訊，一定另有圖示或文字。

## 字型

- 中文：芫荽 Iansui（Google Fonts，只有一種粗細）。
- 數字與英文：Nunito 700、800、900。
- 一律寫 `font-family: Nunito, Iansui, sans-serif`，數字自動用 Nunito、中文自動用芫荽；加上 `font-synthesis: none`，中文不會被瀏覽器假加粗。強調中文改用字級、顏色或貼紙。

## 形狀

- 外框：卡片 2.5px、按鈕與輸入框 2px、格子裡的小貼紙 1.5px，全部用 ink。
- 硬陰影：卡片與主要按鈕 `3px 3px 0 ink`，小按鈕 `2px 2px 0 ink`。按下時往右下移 2px、陰影變小，像把貼紙按下去。
- 圓角：卡片 20px、按鈕 12–16px、格子貼紙 6–10px，其餘圓形。
- 傾斜只用在點綴：紙膠帶、選中的月份、週合計標籤、印章、提示貼紙，角度在 ±7° 內。

## 版面

| 寬度 | 版面 |
| --- | --- |
| 手機（< 768px） | 單欄：頂列 → 月份標籤列 → 本月卡 → 日曆卡；編輯從底部滑出 |
| 平板（768–1023px） | 單欄，格子放大 |
| 桌面（≥ 1024px） | 頂列含整排月份；左邊日曆，右邊 370px 側欄放本月卡與圖例；點日期時側欄換成編輯卡 |

## 元件與行為

### 頂列
貓頭像加「工時貓」；年份下拉（前後 5 年）；今天按鈕（跳到本月）；齒輪（連線設定）。圖示按鈕都要有 `aria-label`。

### 月份標籤列
- 跨年連續，每年 1 月前面有年份分隔（例如 `2027`），點下一年的月份就會切年。
- 選中的月份放大、天藍底、微微傾斜，切換後自動捲到中間。

### 本月卡
- **圓環：** 週合計加總 ÷ 應上班時數。超過 100% 時圓環畫滿、變綠，百分比標籤照實顯示（例如 101%）。沒填應上班時數時圓環改成虛線。
- **應上班時數：** 0～744，可留空。輸入不合法時紅框加說明，並改回原本的值，例如「999 超出 0～744，已改回 176」。
- **已排 X h：** 等於週合計加總。
- **貓咪的話：** 見下方文案表。
- **同步印章：** 蓋在卡片右上角，見下方狀態表。

### 日曆卡
- 週一開始；只顯示當月日期，其他月份的格子留白。
- 格子內容：日期；時間（有填實際用實際，否則用原定；整點補零，例如 `09`、`21.5`），時間下方有天藍螢光筆線。
- 假別：格子底色加右上角圖示貼紙（例假月亮、休假咖啡杯、國定假日旗子）。沒填時間的格子，左下另貼文字標籤（例假、休假、國定）。
- 今天：日期數字畫圈、淡藍底、角落一個貓掌。
- 桌面版編輯中的那一天：奶黃底加粗框。
- 每週右側的週合計標籤：大於 0 是天藍貼紙，等於 0 是虛線框。
- 底部收據：週合計加總、加班時數。沒填應上班時數時不顯示加班時數；負數照常顯示，正數用 green-text。

### 編輯面板
- 手機是底部面板，貓坐在面板上緣；桌面是側欄卡，右上角有關閉按鈕。標題是「11月3日 星期二」。
- **原定 / 實際分頁：** 分頁上顯示該組時間摘要。有填實際時，實際分頁標「以這組為準」並顯示當天時數。
- **時間軸 6–22：** 原定是斜線藍條，實際是珊瑚紅條，兩組一眼比較。
- **上班 / 下班兩格：** 點哪格就編輯哪格。選完上班的分鐘後，自動切到下班。
- **小時按鈕：** 06–21，手機 8×2、桌面 4×4；**分鐘按鈕：** 0、.25、.5、.75；「清除這組」清空目前分頁的上下班。
- **假別：** 無、例假、休假、國定假日，四選一。
- **按鈕：** 刪除（只有已有紀錄時顯示）、取消、儲存。
- **驗證訊息沿用現在的文字：**「原定上班與下班時間需要同時選擇」、「實際下班時間需要晚於上班時間」、「請選擇上下班時間或假別」等，顯示在面板內，不關閉面板。

### 連線設定卡
- 第一次使用時自動出現，貓咪說「嗨！我是工時貓，先幫我連上你的試算表吧～」；之後從齒輪打開同一張卡。
- 網址必須是 `https://script.google.com/…/exec`；錯誤時紅框加說明（例如貼成 `/dev` 時提示要用 `/exec`）。
- 密鑰預設隱藏，可切換顯示。設定只存在這台裝置；換成另一個網址時，清掉本機快取與待同步變更（沿用現在的行為）。

### 薪資卡
- 放在日曆下方（手機與桌面都一樣），標題「11 月薪資試算」，右上兩個按鈕：「編輯本月」（天藍）、「常用類別」。右上角蓋紙膠帶。
- 沿用前面月份的設定時，標題下方有一行藍色小提示「沿用 N 月的設定」。
- **預估實領：** 奶黃色貼紙，**不旋轉**，金額 30px 粗體，字寬固定（tabular）。
- **加項、扣項分成兩個區塊：** 加項是綠色外框、淡綠底、綠色「＋」圓章，合計用綠色；扣項是紅色外框、淡紅底、紅色「－」圓章，合計與每一行金額用紅色並帶負號。沒有扣項時顯示「這個月沒有扣項」。
- **每一行：**「名稱（小字說明）…… 金額」，中間用點線連接，同日曆底部的收據。金額的進位方式設成「不進位」時，所有金額一律顯示兩位小數，位數才會對齊；算式裡除不盡的時薪寫成 `122.9167…`，卡片底部註明目前的進位方式。
- **提醒：** 卡片底部用小字列出（藍色圓點 ⓘ）：還差幾小時才算加班、時薪怎麼來的；紅色警告：低於基本工資、後端還沒更新。
- **這個月還沒有設定：** 改顯示邀請卡（錢袋圖示、「N 月還沒有薪資設定」、「設定這個月」與「常用類別」按鈕）。月份還沒載入時，實領顯示「–」。
- 底部固定一行「試算僅供參考，實際金額以公司薪資單為準」。

### 每月薪資設定視窗
- 原生 dialog，手機上接近全螢幕；內容可捲動，標題與底部的「取消／儲存」固定不動。標題「11 月薪資設定」。
- 最上面一條藍色說明：「從 N 月起生效，不會影響更早的月份」，沿用時改成「目前沿用 N 月的設定」。
- 順序：身分 → 本薪或時薪 → 時薪進位方式（三選一，下方即時顯示換算過程，除不盡的寫成 `122.9167…`）→ **金額的進位方式**（三選一，下方範例：加班 10 小時 × 時薪 × 1.34 = 乘出來的完整數字 → 進位後的金額）→ **加項區塊**（綠）→ **扣項區塊**（紅）→ 說明 →（有自己的設定時）「清除本月設定」。
- **加項、扣項區塊：** 每個項目兩行——名稱加刪除鈕；「NT$／%」單位切換加數值，右邊是「每月沿用／只限本月」切換（藍色實線＝沿用，灰色虛線＝只限本月）。
- **快速加入：** 區塊下方一排膠囊按鈕，是常用類別（加項偏綠、扣項偏紅），點了帶入名稱與預設值並把游標移到金額；最後一顆虛線的「自訂加項／扣項」是非經常性項目，游標移到名稱。「管理常用類別」文字連結打開常用類別視窗（疊在上面，不會洗掉正在填的內容）。
- 輸入框 44–48px 高、字級 18px（避免 iOS 放大），刪除鈕紅框；數值 0 顯示為空白加灰色 0 提示。
- 「清除本月設定」要點兩次（第二次變成「確定清除？」）。錯誤顯示在底部按鈕上方，視窗保持開啟；工讀生時薪或正職本薪低於基本工資時，顯示紅色提醒（不擋儲存）。

### 常用類別視窗
- 說明一行，下面是「常用加項」（綠）與「常用扣項」（紅）兩個區塊，每個類別兩行：名稱加刪除鈕；「NT$／%」切換加預設值。每區塊底下有「新增常用加項／扣項」，視窗最下方有「還原成預設的類別」。
- 刪除類別不會動到已經加進月份的項目，只是不再出現在快速加入。

### 其他
- **錯誤卡：** 沒看過的月份又連不上時，取代本月卡位置，說明原因，附「重試」與「設定」；日曆顯示骨架。
- **提示貼紙：** 儲存成功顯示「記下了！11月3日 12.5h」，3 秒後消失；試算表拒絕的變更顯示紅色貼紙，留到按「知道了」，畫面改回試算表裡的內容。
- **載入骨架：** 格子裡淡淡的貓掌。

## 貓咪的話

由上往下，第一個符合的條件生效：

| 條件 | 文案 |
| --- | --- |
| 還沒填應上班時數 | 填上時數，我幫你算加班 |
| 這個月還沒有任何時數 | 點日期開始記錄吧 |
| 已排少於應上班 | 還差 X 小時，加油喵 |
| 已排剛好等於應上班 | 剛好達標，辛苦了喵！ |
| 已排多於應上班 | 達標啦，多了 X 小時，辛苦了喵！ |

## 同步印章

| 狀態 | 印章 | 點印章 |
| --- | --- | --- |
| 都同步了 | 綠「已同步」 | 無動作 |
| 正在載入或送出 | 藍「同步中」加轉圈 | 無動作 |
| 有變更沒送出（離線） | 橘「離線・N 筆待同步」 | 重試 |
| 顯示的是快取，更新失敗 | 橘「顯示上次的資料」 | 重試 |
| 設定有問題（未設定、密鑰錯、網址錯） | 紅，例如「密鑰不正確」 | 打開連線設定 |

## 動態

- 面板滑入 250ms；提示貼紙彈出、3 秒後淡出；切換月份時日曆淡入 150ms。
- 第一次達標時撒一次彩帶；印章狀態改變時輕輕晃一下。
- 系統開啟「減少動態效果」時，全部改成直接出現。

## 無障礙

- 日期格子的 `aria-label` 寫完整內容，例如「11月3日，實際 9.25 至 21.75，國定假日」。
- 小時、分鐘、假別按鈕是單選群組（radiogroup），可用鍵盤操作。
- 焦點框用 3px ink 外框，不可拿掉。

## 不做

- 深色模式。

## 實作

- 前端用 Svelte 5 + TypeScript 實作，原始碼在 `web/`；元件對照：薪資卡 `SalaryCard`、每月薪資設定視窗 `PayMonthDialog`、常用類別視窗 `CategoriesDialog`、加扣項編輯 `PayItemsEditor`、金額欄位 `AmountField`、設定視窗外框 `Modal`、頂列 `TopBar`、月份標籤列 `MonthStrip`、本月卡 `MonthCard`、同步印章 `Stamp`、日曆 `Calendar`、編輯面板 `Editor`、連線設定 `Settings`、錯誤卡 `ErrorCard`、提示貼紙 `Toast`、圖例 `Legend`。
- 與稿子不同的地方：同步印章一直蓋在本月卡上，達標改用圓環旁的獎盃徽章表示；今天的格子有時間時不放貓掌，避免壓到數字。
